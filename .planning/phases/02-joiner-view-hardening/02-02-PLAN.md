<objective>
Move CodeMirror's `history()` extension into a new `historyCompartment` so the
joiner branch of `enableCollab` can reconfigure it to `[]`, removing
`historyField` from the joiner's EditorState entirely. This satisfies
JOINER-01's assertion that `view.state.field(historyField, false) ===
undefined` on a freshly-connected joiner.

Purpose: per 02-RESEARCH §3, `history()` is currently injected by
`getExtensions()` (extensions.ts:92), NOT the collab module. The joiner reuses
the live EditorView and only reconfigures `collabCompartment`, so `history()`
stays alive — failing JOINER-01. The fix is a second compartment dedicated to
`history()` plus a one-effect addition in the joiner-side dispatch.

Output: One additive `historyCompartment` export + a 2-effect dispatch in the
joiner branch + symmetric restore in `disableCollab`.
</objective>
