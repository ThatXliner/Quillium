```typescript
private updatePendingCount() {
    const pending = sendableUpdates(this.view.state).length;
    pendingUpdatesCount.set(pending);
    // Update collabState to reflect syncing when we have pending updates
    if (pending > 0) {
        // Only set to syncing if currently connected (not if reconnecting/error)
        import { get } from "svelte/store";
        const currentState = get(collabState);
        if (currentState === "connected") {
            collabState.set("syncing");
        }
    }
}
```

Actually, to avoid import issues, use subscribe pattern instead. Add a class field and update approach:

```typescript
private pendingCount = 0;

private updatePendingCount() {
    const pending = sendableUpdates(this.view.state).length;
    if (pending !== this.pendingCount) {
        this.pendingCount = pending;
        pendingUpdatesCount.set(pending);
    }
}
```

5. In the `destroy()` method, reset the pending count:
```typescript

    // ... existing cleanup
```
