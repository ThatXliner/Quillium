## Component Specifications

### Name Entry Modal

**Context:** Appears when anonymous user opens a shared document link. Per D-23: triggers only when joining, not on app startup. Per D-22: lightweight feel, not a full sign-up form.

**Layout:**
- Modal width: 320px (narrower than auth modal's 360px - simpler form)
- Modal radius: 1rem (16px)
- Modal shadow: `0 25px 50px -12px rgba(0, 0, 0, 0.2)`
- Backdrop: `rgba(0, 0, 0, 0.25)` with `backdrop-filter: blur(4px)`

**Header:**
- Height: 48px
- Padding: `px-5 py-3` (20px horizontal, 12px vertical)
- Title: "Join Document" (16px, font-semibold, text-black/60)
- Close button: X icon (15px), with "esc" hint badge

**Content:**
- Padding: `px-5 py-4` (20px horizontal, 16px vertical)
- Gap between elements: 16px (gap-4)

**Input Field:**
- Label: "Your name" (12px, text-black/50)
- Input: `px-3 py-2 text-sm border border-black/10 rounded-lg`
- Placeholder: "How should others see you?"
- Focus: `focus:ring-2 focus:ring-blue-500/40`
- Autocomplete: `name`

**Primary Button:**
- Full width
- Padding: `px-4 py-2` (16px horizontal, 8px vertical)
- Text: 14px, font-semibold, white
- Background: blue-500
- Hover: blue-600
- Radius: rounded-lg (8px)
- Disabled state: opacity-50, cursor-not-allowed

**Optional: Sign In Link**
Per D-26: Anonymous user can sign in while viewing a shared doc
- Position: Below primary button
- Text: "Already have an account? Sign in" (12px, text-black/40)
- Hover: text-blue-500

Source: D-20, D-22, existing AuthModal.svelte patterns

## Interaction Flow

1. User opens shared document link
2. If already authenticated (D-25): skip modal, join directly
3. If anonymous: show Name Entry Modal
4. User enters display name
5. On submit: call `signInAnonymously(displayName)`
6. On success: close modal, load document
7. On error: show error message inline, keep modal open

**Keyboard shortcuts:**
- Enter: submit form
- Escape: close modal (cancel join)

Source: D-23, D-25
