# Phase 6.5: Collab Polish - Context

**Gathered:** 2026-04-17
**Status:** Ready for planning

<domain>
## Phase Boundary

Essential UX polish for usable collab sessions. Live cursors show other users' cursor positions in real-time. When owner disconnects, all clients are kicked with clear message. Developer documentation explains how to run the full collab setup.

</domain>

<decisions>
## Implementation Decisions

### Live Cursor Display
- **D-60:** Google Docs-style cursors — colored caret line with name label above, each user gets a distinct color

### Owner Disconnect Handling
- **D-61:** No warning before kick — when owner disconnects, collaborators are immediately disconnected with a toast notification explaining what happened

### Developer Setup Docs
- **D-62:** Step-by-step documentation with copy-pastable commands — full walkthrough including relay deployment, env vars, Supabase setup, and local dev. Every command ready to paste directly into terminal.

### Claude's Discretion
- Cursor color palette and assignment strategy (random vs deterministic)
- Cursor fade behavior when user is idle
- Exact toast message wording for owner disconnect
- Documentation file location and structure

</decisions>
