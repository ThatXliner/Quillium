# Quick Task: Initial Annotation Sync

## Problem

When a joiner connects to a collab room that already has annotations (comments, revisions), they don't see them. The `createAnnotationSyncPlugin` constructor:
1. Registers existing CM annotations in the ID map (`_syncIdMapFromCM`)
2. Sets up `observeDeep` for **future** changes
3. **Never pulls existing annotations FROM Yjs to CodeMirror**

This means pre-existing annotations in the Y.Map are invisible to joiners.

## Solution

Add initial sync in the plugin constructor: iterate over `scopeAnnotations`, convert each node via `yjsAnnotationToCodeMirror`, and dispatch `addAnnotation` effects.

## Tasks

### Task 1: Add initial sync logic to plugin constructor

**Files:** `src/lib/collab/yjsAnnotations.ts`

**Action:**
1. After `_syncIdMapFromCM()` call, iterate `scopeAnnotations.forEach()`
2. For each annotation node, call `yjsAnnotationToCodeMirror()` to convert
3. Register in idMap via `getOrCreateCmId()`
4. Collect `addAnnotation.of()` effects
5. If effects non-empty, dispatch with `yjsAnnotationSync.of(true)` annotation

**Verify:** Write or update test in `yjsAnnotations.test.ts` for "syncs existing annotations on mount"

**Done:** Plugin constructor loads pre-existing annotations on mount
