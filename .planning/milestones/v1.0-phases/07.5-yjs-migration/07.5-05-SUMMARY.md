## Technical Decisions

### WebSocket Upgrade Handler

Per D-71, authentication moved from Socket.io middleware to HTTP upgrade handler:
- JWT token passed as `?auth=` query parameter
- Document ID extracted from URL path (`/docId`)
- Auth validation before WebSocket upgrade
- 401 response on auth failure (no WebSocket established)

### Room Manager Pattern

`rooms.ts` follows the existing `rooms/manager.ts` pattern but for Yjs:
- `getOrCreateYjsRoom` loads Y.Doc state from DB on room creation
- `scheduleRoomCleanup` with 45s delay per D-37
- Persists final Y.Doc state before cleanup
- Destroys Awareness and Y.Doc to prevent memory leaks

### Health Check Protocol Field

Added `protocol: "yjs"` to health check response to distinguish from Socket.io server during migration verification.

## Key Files

### supabase/migrations/20260417180000_yjs_tables.sql

Creates two tables for Yjs persistence:
- `yjs_documents`: Full state snapshots (base64 encoded Uint8Array)
- `yjs_updates`: Incremental updates for crash recovery

Both reference `sync_documents(id)` with CASCADE delete.

### relay/src/yjs/rooms.ts

Exports:

- `getYjsRoom(documentId)` - Gets existing room
- `scheduleRoomCleanup(room)` - 45s cleanup delay
- `cancelRoomCleanup(room)` - Cancel pending cleanup
- `getRoomCount()` - For health check
- `_clearAllRooms()` - For testing

### relay/src/server.ts

Exports:
- `createRelayServer()` - Returns `{ wss, httpServer }`

Features:
- Native WebSocket via `ws` package
- Auth in `httpServer.on("upgrade")` handler
- Calls `setupYjsConnection` for Yjs sync
- Persistence callback via `persistYjsUpdate`

### relay/src/auth/middleware.ts

New export:
- `authenticateWebSocket(token, documentId)` - For WebSocket upgrade auth

Validates JWT via `supabase.auth.getUser()`, checks document ownership.

## Integration Points

The relay server is now ready for Yjs clients:
- Connect via `ws://relay-url/{documentId}?auth={jwt}`
- Server establishes Yjs sync protocol (MESSAGE_SYNC, MESSAGE_AWARENESS)
- Updates persisted to `yjs_updates` table
- Room state persisted to `yjs_documents` on cleanup
