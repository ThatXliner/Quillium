## Integration Test: Two-Client Sync

### Setup (Terminal 1 - Relay)
```bash
cd /Users/bryanhu/Developer/current/quillium-landing/relay
bun run dev
```
Expected: Server starts, shows "listening on port 3001" (or configured port)

### Setup (Terminal 2 - Client A)
```bash
cd /Users/bryanhu/Developer/current/Quillium
bun run dev
```
Open http://localhost:1420 in Browser A

### Setup (Terminal 3 - Client B)
Open http://localhost:1420 in Browser B (different browser or incognito)

### Test 1: Basic Sync
1. In Client A: Log in, open a document, click "Go Live"
2. Copy the share link (or note the document ID)
3. In Client B: Log in, join via share link
4. In Client A: Type "Hello from A"
   - Expected in Client B: Text appears within ~100ms
5. In Client B: Type " and B"
   - Expected in Client A: Text appears, showing "Hello from A and B"

### Test 2: Concurrent Edits
1. In Client A: Position cursor at start of document
2. In Client B: Position cursor at end of document
3. Simultaneously:
   - Client A types "START-"
   - Client B types "-END"
   - Expected: Both edits appear, document converges to same content

### Test 3: Per-User Undo
1. In Client A: Type "AAA"
2. In Client B: Type "BBB"
3. In Client A: Press Cmd/Ctrl+Z
   - Expected: "AAA" is undone, "BBB" remains
4. In Client B: Press Cmd/Ctrl+Z
   - Expected: "BBB" is undone, undo stacks are independent

### Test 4: Cursor Display
1. Both clients should see the other's cursor
2. Cursor should have name label above it
3. Cursor should have distinct color
4. Moving cursor should update in other client

### Test 5: Owner Disconnect (D-57, D-61)
1. In Client A (owner): Click "Stop Live" or close browser
2. In Client B:
   - Expected: Connection ends
   - Expected: Toast notification about owner leaving
   - Expected: No longer receiving updates

### Test 6: Reconnection
1. In Client A: Kill the relay server (Ctrl+C in Terminal 1)
2. Expected: Client shows "reconnecting" state
3. Restart relay: `bun run dev`
4. Expected: Client reconnects and syncs

### Verification Checklist
- [ ] Two clients see each other's edits in real-time
- [ ] Concurrent edits converge to same document
- [ ] Per-user undo only undoes local changes
- [ ] Remote cursors visible with name labels
- [ ] Owner disconnect kicks collaborators
- [ ] Reconnection recovers sync state
