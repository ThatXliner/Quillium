Add the `findOwningAnnotationId` helper as a module-level function:

```typescript
/**
 * Walk up from a Y.Text/Y.Map/Y.Array inside a subtree until we reach the
 * doc-level ymap, recording the top-level annotation key and (if present)
 * the version index. Returns null if the type does not belong to any
 * annotation subtree in this session.
 */
function findOwningAnnotationId(
    yType: Y.AbstractType<unknown>,
    docYmap: Y.Map<unknown>,
    mainIdMap: AnnotationIdMap,
): { cmId: number; versionIndex?: number } | null {
    // Walk parents collecting (parent, child) pairs until parent === docYmap.
    // Depth cap (T-08.5-06-02): Yjs's parent pointers form a tree (acyclic), but
    // we defensively bound the walk to MAX_DEPTH to prevent infinite loops on
    // malformed data. Our shape tops out at 4 levels (docYmap → annotation node
    // → versions map → version node → text/annotations); 16 is generous.
    const MAX_DEPTH = 16;
    let depth = 0;
    type Step = { parent: Y.AbstractType<unknown>; child: Y.AbstractType<unknown> };
    const stack: Step[] = [];
    let current: Y.AbstractType<unknown> = yType;
    while (current.parent && current !== docYmap) {
        if (depth > MAX_DEPTH) {
            console.warn(
                "[collab] findOwningAnnotationId exceeded MAX_DEPTH; aborting walk",
            );
            return null;
        }
        stack.push({ parent: current.parent as Y.AbstractType<unknown>, child: current });
        current = current.parent as Y.AbstractType<unknown>;
        depth += 1;
    }
    if (current !== docYmap) return null;

    // Top step: parent is docYmap, child is the annotation node's Y.Map.
    // Scan docYmap entries for a value === child.
    const topStep = stack[stack.length - 1];
    if (!topStep) return null;
    let annotationYjsId: string | null = null;
    docYmap.forEach((value, key) => {
        if (value === topStep.child) annotationYjsId = key;
    });
    if (!annotationYjsId) return null;
    const cmId = mainIdMap.getCmId(annotationYjsId);
    if (cmId === undefined) return null;

    // Optional: detect a version index by scanning for a step whose parent
    // is the annotation node's `versions` Y.Map.
    const annotationNode = docYmap.get(annotationYjsId) as Y.Map<unknown> | undefined;
    const versionsMap = annotationNode?.get("versions");
    let versionIndex: number | undefined;
    if (versionsMap instanceof Y.Map) {
        for (const step of stack) {
            if (step.parent === versionsMap) {
                // step.child is a version Y.Map; find which key it's under.
                versionsMap.forEach((value, key) => {
                    if (value === step.child) versionIndex = Number(key);
                });
                break;
            }
        }
    }

    return { cmId, versionIndex };
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UndoManager listener → UI event bus | A stack-item-popped event surfacing a subtree change triggers a UI navigation. If a peer could forge an undo that pops *their* stack item referring to *our* subtree, we'd scroll the wrong revision into view. |
| findOwningAnnotationId over docYmap | Walks arbitrary Y.AbstractType parents; must not infinite-loop on malformed data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08.5-06-01 | Spoofing | Remote peer's undo causes local navigation | accept | `trackedOrigins: new Set(["local"])` ensures only local edits enter THIS peer's UndoManager; `stack-item-popped` only fires for local stack operations. Remote undo is not possible under D-74. |
| T-08.5-06-02 | Denial of Service | findOwningAnnotationId loops forever on a cyclic parent reference | mitigate | Yjs's parent pointer is a tree (acyclic); we add a defensive depth cap (e.g. 16) and break with a `console.warn` if exceeded. |
| T-08.5-06-03 | Information Disclosure | `annotationEventBus.emit` delivers undo-target to any listener including AI components | accept | The only existing subscribers are Revision.svelte / RevisionModal.svelte. Future listeners would need explicit opt-in; the event contains no confidential data. |
| T-08.5-06-04 | Denial of Service | stack-item-popped listener raises during emit and breaks UndoManager state | mitigate | Wrap the emit block in a try/catch and `console.error` on failure; the UndoManager itself continues unaffected. |
</threat_model>
