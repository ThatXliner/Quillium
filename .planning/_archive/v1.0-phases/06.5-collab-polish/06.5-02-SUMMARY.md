## Deviations from Plan

### Omitted: RELAY_SKIP_AUTH Documentation

**Reason:** The plan specified documenting `RELAY_SKIP_AUTH=1` for local dev without Supabase, but inspection of `quillium-landing/relay/src/auth/middleware.ts` shows this feature is not implemented. The middleware always requires Supabase configuration and does not check for a skip-auth environment variable.

**Resolution:** Omitted this section rather than document a non-existent feature. A future plan can add this feature and update the docs.
