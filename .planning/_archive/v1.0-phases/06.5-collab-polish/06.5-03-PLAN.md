<objective>
Client-side remote cursor module: StateField, ViewPlugin, WidgetType, CSS theme, and emit plugin (D-60).

Purpose: Implements the Google Docs-style cursor display for remote users. This is a self-contained CodeMirror extension that: (1) receives cursorUpdate events from socket and stores positions in a StateField, (2) maps positions through document changes automatically, (3) renders a colored caret + name label via Decoration.widget, (4) emits the local user's cursor position to the relay at a throttled rate.

Output: `src/lib/collab/cursors.ts` (full module) and `src/lib/collab/cursors.test.ts` (unit tests).

StateField (positions map through doc changes):
```typescript
export const remoteCursorsField = StateField.define<Map<string, RemoteCursor>>({
    create() { return new Map(); },
    update(cursors, tr) {
        let next = cursors;
        for (const effect of tr.effects) {
            if (effect.is(setRemoteCursor)) {
                next = new Map(next);
                next.set(effect.value.clientID, effect.value);
            } else if (effect.is(removeRemoteCursor)) {
                next = new Map(next);
                next.delete(effect.value);
            }
        }
        // Map positions through doc changes — side: 1 keeps cursor after inserted text
        if (tr.docChanged && next.size > 0) {
            next = new Map(
                [...next.entries()].map(([id, cursor]) => [
                    id,
                    { ...cursor, pos: tr.changes.mapPos(cursor.pos, 1) },
                ])
            );
        }
        return next;
    },
});
```

Color palette (deterministic hash):
```typescript
const CURSOR_COLORS = [
    "#4A90E2", "#E87040", "#50B86C", "#9B59B6",
    "#E74C3C", "#16A085", "#F39C12", "#8E44AD",
];
export function colorForClient(clientID: string): string {
    let hash = 0;
    for (let i = 0; i < clientID.length; i++) {
        hash = ((hash << 5) - hash) + clientID.charCodeAt(i);
        hash |= 0;
    }
    return CURSOR_COLORS[Math.abs(hash) % CURSOR_COLORS.length];
}
```
