## Architecture Notes

### stack-item-popped Event Flow

```
User presses Ctrl-Z in main editor
    ↓
Y.UndoManager.undo() pops stack item
    ↓
"stack-item-popped" event fires
    ↓
Listener iterates changedParentTypes.keys()
    ↓
findOwningAnnotationId walks parent chain → { cmId, versionIndex }
    ↓
annotationEventBus.emit({ type: "undo-target", ... })
    ↓
Revision.svelte / RevisionModal.svelte consume event → scroll/open modal
```

### findOwningAnnotationId Contract

- **Input:** Any Y.AbstractType (Y.Text, Y.Map, Y.Array) from a subtree
- **Output:** `{ cmId: number; versionIndex?: number }` or null
- **Walk:** Follows `.parent` pointers up to doc-level ymap
- **Depth cap:** 16 levels max (our shape is 4 levels)
- **Key resolution:** Scans parent Y.Map entries to find matching child reference
