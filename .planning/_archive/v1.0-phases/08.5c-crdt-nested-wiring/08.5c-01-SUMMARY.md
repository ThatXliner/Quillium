## Architecture Notes

The key insight is that when collab is active, the subtree Y.Text IS the source of truth for nested editor content. This means:

1. **No JSON blob flush** — `translateAndDispatch()` is bypassed; edits flow directly through Yjs
2. **No Phase 3 doc-pulling** — `pushDocToVersionState()` is bypassed; the parent doesn't overwrite subtree content
3. **Undo via Yjs** — `addSubtreeToUndoScope()` registers the subtree with the global UndoManager
4. **breakUndoCapture** on destroy — ensures the next nested editor session starts fresh
