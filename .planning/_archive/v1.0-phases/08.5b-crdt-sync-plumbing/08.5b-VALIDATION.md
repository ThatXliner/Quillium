## Layer Convention

Per `memory/feedback_convergence_debugging.md` — each failure mode must have a failing test at the correct layer BEFORE a fix is proposed.

| Layer | What it tests | Test file |
|-------|---------------|-----------|
| subtree-binding | Y.Text ↔ CodeMirror subtree binding fidelity (delta application round-trip) | `src/lib/collab/subtree-binding.test.ts` |
| undo-manager | Y.UndoManager behavior: scope, origin filtering, addToScope, events | `src/lib/collab/undo-manager.test.ts` |
| version-coordination | `versions: Y.Map` structural ops, active version pill semantics (D-99) | `src/lib/collab/version-coordination.test.ts` |
| annotation-tree | Recursive Y.Map shape integrity, observeDeep fidelity, ID uniqueness | `src/lib/collab/annotation-tree.test.ts` |
| convergence (2-peer) | End-to-end convergence: two Y.Doc instances + update exchange, final state compare | `src/lib/collab/subtree-convergence.test.ts`, `src/lib/collab/convergence-edgecases.test.ts` |
