## Key Implementation Details

### enableCollab Flow

```typescript
// 1. Connect to Yjs relay
const { provider, awareness, ydoc, ytext } = await createYjsProvider(docId);

// 2. Wait for initial sync
await new Promise((resolve) => provider.synced ? resolve() : provider.once("sync", resolve));

// 3. Determine authoritative content (owner seeds empty rooms)
if (asOwner && remoteContent.length === 0 && localDoc.length > 0) {
    ydoc.transact(() => ytext.insert(0, localDoc), "init");
}

// 4. Sync editor to authoritative content
view.dispatch({ changes: { from: 0, to: view.state.doc.length, insert: authoritativeContent } });

// 5. Install Yjs extensions
view.dispatch({
    effects: collabCompartment.reconfigure([binding, undoExt, awarenessExt]),
});
```

### Types Updated for Yjs

```typescript
// Old (OT-based)
type CollabSession = { docId, version, clientID, isOwner };
```
