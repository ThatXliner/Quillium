# Architecture

Start with the [architecture walkthrough](docs/architecture-overview.md). It
explains the writing model, follows an edit through the system, and identifies
which package owns each part.

Then read [state management](docs/state-management.md) before changing editor
behavior. Use the [code map](docs/file-structure.md) to find implementations and
the [developer guide](docs/README.md) to choose a subsystem reference.

[CONTEXT.md](CONTEXT.md) defines domain terms. The
[architecture decision records](docs/adr/README.md) explain decisions and tradeoffs.
